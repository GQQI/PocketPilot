# PocketPilot（口袋领航）使用指南

PocketPilot 让你在手机上遥控电脑里的编码代理（Cursor / Claude Code 等 CLI）。电脑端运行 **host**，手机端安装 **APK**（或用浏览器打开 PWA），两者通过 **WebRTC 数据通道 + 公共 MQTT 信令** 端到端加密直连，不需要在同一个 Wi‑Fi。

## 1. 电脑上启动

前置：Node.js ≥ 20（推荐 22），仓库根目录已执行过 `npm install`。

**一条命令（PowerShell，开启远程配对）：**

```powershell
npm run build; $env:POCKETPILOT_RTC="1"; $env:POCKETPILOT_REMOTE="1"; node scripts\serve-host.mjs --lan
```

- `POCKETPILOT_RTC=1`：启用 WebRTC + MQTT 远程通道，并在终端打印配对二维码。
- `POCKETPILOT_REMOTE=1`：远程模式，电脑本机浏览器也必须配对，配对码不会通过 HTTP 暴露。
- `--lan`：监听 0.0.0.0，同一局域网内的手机也可直接用地址 + 配对码连接。
- 只在本机试用可直接 `npm run host`（先构建再启动，默认端口 47232）。
- 后台运行并写日志：`Start-Process node -ArgumentList 'scripts\serve-host.mjs','--lan' -RedirectStandardOutput host.log -RedirectStandardError host.err.log -WindowStyle Hidden`（先设好上面的环境变量）。
- 健康检查：浏览器或 `curl http://127.0.0.1:47232/api/health` 返回 `{"ok":true,...}` 即正常。

**可选：Electron 桌面版**

```powershell
npm run desktop          # 构建并以桌面窗口运行
npm run desktop:dist:win # 打包 Windows 安装程序（apps/desktop/release）
```

> 旧版本升级：环境变量 `MOBILEAGENT_*` 仍然兼容（等同于 `POCKETPILOT_*`）；首次启动时若只有旧目录 `~/.mobileagent`，会自动复制到 `~/.pocketpilot`（旧目录保留作备份），已配对设备不受影响。

## 2. 显示配对二维码 / 配对码

- **终端**：host 启动后会打印
  - 一个二维码和一条以 `#pair=` 结尾的链接（5 分钟内有效，只能使用一次）；
  - 6 位配对码（`pairing code ...`），用于同一局域网下“地址 + 配对码”的方式；每次成功配对后配对码会轮换。
- **已配对设备上**：设置 → “扫码配对（跨网络）” → “生成二维码”，可以再显示一个新的二维码，用于添加更多手机。
- 二维码过期后：重启 host，或在已配对设备的设置页重新生成。

## 3. 手机安装 APK

1. APK 位置：`dist-android\PocketPilot-debug.apk`（构建方法见第 7 节），用微信/数据线/网盘传到手机。
2. 手机上点击 APK 安装。首次需要允许“安装未知应用”：设置 → 应用 → 特殊应用权限 → 安装未知应用 → 允许你用来打开 APK 的应用（文件管理器/浏览器/微信）。部分系统会弹出“风险应用”提示（debug 签名），选择“仍然安装”。
3. 安装后图标名为 **PocketPilot**。APK 内置了完整界面，离线即可打开，不依赖电脑托管网页。

## 4. 打开后扫码或输入配对码

在 App 的“连上你的电脑”页面：

- **扫码**：点“扫码配对”，授权相机，对准电脑终端/设置页的二维码；
- **粘贴链接**：在输入框粘贴 `...#pair=xxxx.yyyy` 链接，点“配对”；
- **同一局域网用配对码**：在“电脑地址”填 `http://电脑局域网IP:47232`，在“配对码”填终端里的 6 位码，点“连接”（需要 host 用 `--lan` 启动，且电脑防火墙放行 47232 端口）。

配对成功后 App 会记住这台电脑，之后打开即自动通过加密通道重连。

## 5. 不在同一网络时怎么连

使用二维码 / 链接配对（第 4 步的“扫码”或“粘贴链接”）即可：手机和电脑各自通过公共 MQTT 服务器交换（已端到端加密的）信令，再用 WebRTC 建立直连数据通道，所以手机用 4G/5G、电脑在家里/公司都可以。要求：

- 电脑能访问互联网（MQTT 与 STUN 服务）；
- 电脑上的 host 正在运行（`POCKETPILOT_RTC=1`）；
- 配对码方式只适用于同一局域网，跨网络请用二维码/链接。

## 6. 已知限制

- **没有 TURN 中继**：只用 STUN 打洞。若电脑或手机处于**对称型 NAT**（部分公司网络、校园网、部分运营商 CGNAT），可能连不上，会提示“无法建立连接”。可自备 TURN/换网络，或让两端处于同一局域网。
- 公共 MQTT 仅用于交换加密信令，不会看到内容；但服务可用性取决于第三方公共服务器，可用 `POCKETPILOT_BROKERS` 指定自己的 MQTT。
- 当前 APK 为 **debug 签名**，仅供自用；release 签名见第 7 节。
- 二维码有效期 5 分钟、单次有效；错误尝试过多会被限速。
- 没有 Google Play 服务的手机会自动退回到 WebView 摄像头扫码，需要允许相机权限。
- 手机息屏/切后台太久，连接可能断开，回到前台会自动重连。

## 7. 构建 APK（开发者）

需要 JDK 17 和 Android SDK（platform-tools、platforms;android-34、build-tools;34.0.0）。脚本默认使用 `%USERPROFILE%\jdk-17` 和 `%USERPROFILE%\android-sdk`，也可通过 `JAVA_HOME` / `ANDROID_HOME` 指定，**不会修改系统环境变量**。

```powershell
npm run android:debug     # 输出 dist-android\PocketPilot-debug.apk
# release：先准备 keystore，再设置环境变量（不要提交 keystore/密码）
$env:POCKETPILOT_KEYSTORE="C:\path\to\pocketpilot-release.keystore"
$env:POCKETPILOT_KEYSTORE_PASSWORD="******"
npm run android:release   # 输出 dist-android\PocketPilot-release.apk
```

Capacitor 工程在 `apps/android`（appId `com.pocketpilot.app`）。WebView 来源 `https://localhost` / `capacitor://localhost` 已默认加入 host 的 CORS 白名单（设置 `POCKETPILOT_CAPACITOR_ORIGINS=0` 可关闭）。图标由 `apps/web/public/favicon.svg` 经 `npm run android:icons` 生成。

## 8. 如何撤销设备

- 在任意**已配对**设备（或电脑本机）打开：设置 → 已配对设备 → 找到对应手机 → “撤销”。该设备的令牌立即失效，需要重新配对才能再次访问。
- 手机丢失：在电脑上撤销该设备即可；令牌默认 90 天过期（`POCKETPILOT_TOKEN_TTL_DAYS` 可调）。
- 手机端想“忘记”这台电脑：设置 → “忘记这台电脑”。
- 彻底重置：停止 host，删除 `~/.pocketpilot` 下的设备记录（保留 `secrets.json` 以免丢密钥），重启后需全部重新配对。
