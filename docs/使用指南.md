# PocketPilot（口袋领航）使用指南

PocketPilot 让你在手机上遥控电脑里的编码代理（Cursor / Claude Code 等 CLI）。

- **电脑端**：安装 **PocketPilot 桌面程序**（Windows），双击打开窗口，在窗口里启动服务、显示配对二维码，全程不需要命令行。
- **手机端**：安装 **PocketPilot APK**，扫描电脑上的二维码即可连接。
- 两端通过 **WebRTC 数据通道 + 公共 MQTT 信令** 端到端加密直连，不需要在同一个 Wi‑Fi；同一局域网下也可以用“地址 + 配对码”连接。

## 1. 安装电脑端（桌面程序）

1. 拿到安装包 `PocketPilot-Setup.exe`（构建方法见第 8 节），双击运行。
2. 安装向导可以选择安装目录，并创建桌面快捷方式；安装完成后会自动启动。
3. 安装包目前**没有代码签名**：Windows 可能提示“Windows 已保护你的电脑”，点“更多信息 → 仍要运行”即可。
4. 首次启动若弹出 Windows 防火墙提示，请允许“专用网络”访问（手机在同一 Wi‑Fi 下直连需要）。
5. 不想安装？解压 `PocketPilot-Portable-*.zip`，双击里面的 `PocketPilot.exe` 即可（便携版）。

升级：直接运行新版安装包覆盖安装，已配对的手机和设置都会保留（数据在 `%USERPROFILE%\.pocketpilot`）。

## 2. 首次使用

双击桌面上的 **PocketPilot 口袋领航** 图标，会出现主窗口，服务会自动启动：

- **服务状态卡片**：显示“服务运行中 / 已停止”，右上角开关可以一键启动或停止；下方显示局域网地址和“跨网络通道”状态（已连接的信令服务器数、活跃连接数）。
- **手机配对卡片**：大号二维码、6 位配对码、剩余有效时间；“复制链接”可把 `…#pair=…` 链接发给手机，“刷新二维码”立即换一个新的。二维码 5 分钟有效、只能用一次，过期后自动刷新；手机配对成功时窗口会弹出“配对成功”提示。
- **已配对设备**：列出手机名称和最后在线时间，点“撤销”（再点一次确认）后该手机立即失效。
- **设置**：开机自启、关闭窗口时最小化到托盘、服务端口（默认 47241）、是否允许局域网、是否允许跨网络（RTC）、工作目录、演示模式、各代理的 API 密钥、语言（中文 / English）、版本与日志入口。端口、局域网、跨网络三项修改后服务会自动重启。
- **系统托盘**：关闭窗口默认最小化到托盘，服务继续运行。右键托盘图标可以显示/隐藏窗口、显示二维码、启动/停止服务、退出；左键单击切换窗口显示。

桌面窗口本身不需要配对（通过本机内部通道控制服务），但对外提供的服务始终是**远程模式**：任何手机、浏览器都必须先配对才能访问。服务异常退出时桌面程序会自动重启它。

## 3. 手机安装 APK

1. APK 位置：`dist-android\PocketPilot-debug.apk`（构建方法见第 8 节），用微信/数据线/网盘传到手机。
2. 手机上点击 APK 安装。首次需要允许“安装未知应用”：设置 → 应用 → 特殊应用权限 → 安装未知应用 → 允许你用来打开 APK 的应用（文件管理器/浏览器/微信）。部分系统会弹出“风险应用”提示（debug 签名），选择“仍然安装”。
3. 安装后图标名为 **PocketPilot**。APK 内置了完整界面，离线即可打开，不依赖电脑托管网页。

## 4. 配对：扫码或输入配对码

在手机 App 的“连上你的电脑”页面：

- **扫码（推荐，可跨网络）**：点“扫码配对”，授权相机，对准电脑窗口里的二维码。
- **粘贴链接**：把电脑上“复制链接”得到的 `…#pair=xxxx.yyyy` 粘贴到输入框，点“配对”。
- **同一局域网用配对码**：在“电脑地址”填电脑窗口里显示的局域网地址（如 `http://192.168.3.29:47241`），在“配对码”填 6 位配对码，点“连接”。需要设置里开启“允许局域网访问”，且 Windows 防火墙放行该端口。每次配对成功后配对码会自动更换。

配对成功后 App 会记住这台电脑，之后打开即自动通过加密通道重连；电脑窗口里会立即出现这台手机。

## 5. 不在同一网络时怎么连

使用二维码 / 链接配对即可：手机和电脑各自通过公共 MQTT 服务器交换（端到端加密的）信令，再用 WebRTC 建立直连数据通道，所以手机用 4G/5G、电脑在家里/公司都可以。要求：

- 电脑能访问互联网（MQTT 与 STUN 服务），主窗口“跨网络通道”显示“信令 x/y 已连接”；
- 设置里“允许跨网络（RTC）”保持开启；
- 配对码方式只适用于同一局域网，跨网络请用二维码/链接。

## 6. 已知限制

- **没有 TURN 中继**：只用 STUN 打洞。若电脑或手机处于**对称型 NAT**（部分公司网络、校园网、部分运营商 CGNAT），可能连不上，会提示“无法建立连接”，此时请换网络、用手机热点，或让两端处于同一局域网。同一台电脑上装有多个虚拟网卡/代理隧道时，偶尔需要点“刷新二维码”重试。
- 公共 MQTT 仅用于交换加密信令，不会看到内容；但服务可用性取决于第三方公共服务器，可用 `POCKETPILOT_BROKERS` 指定自己的 MQTT。
- 当前安装包与 APK 均未做正式代码签名（APK 为 debug 签名），仅供自用；release 签名见第 8 节。
- 二维码有效期 5 分钟、单次有效；错误尝试过多会被限速。
- 没有 Google Play 服务的手机会自动退回到 WebView 摄像头扫码，需要允许相机权限。
- 手机息屏/切后台太久，连接可能断开，回到前台会自动重连。

## 7. 撤销设备与重置

- 在电脑主窗口的“已配对设备”里点“撤销”。该设备的令牌立即失效，需要重新配对才能再次访问。
- 手机丢失：在电脑上撤销该设备即可；令牌默认 90 天过期（`POCKETPILOT_TOKEN_TTL_DAYS` 可调）。
- 手机端想“忘记”这台电脑：设置 → “忘记这台电脑”。
- 彻底重置：退出桌面程序，删除 `%USERPROFILE%\.pocketpilot` 下的设备记录（保留 `secrets.json` 以免丢密钥），重启后需全部重新配对。
- 服务日志：设置 → 关于 → “服务日志”（位于 `%APPDATA%\PocketPilot\logs\bridge.log`）。

## 8. 构建（开发者）

需要 Node.js ≥ 20（推荐 22），仓库根目录执行过 `npm install`。

**桌面安装包（Windows）：**

```powershell
npm run build                                   # 构建网页界面和 bridge
npm run desktop:dist:win                        # 输出到 dist-desktop\：PocketPilot-Setup-<版本>.exe（NSIS）和 PocketPilot-Portable-<版本>.zip
npm run desktop                                 # 开发运行桌面程序（不打包）
npm run desktop:icons                           # 由 apps/web/public/favicon.svg 重新生成 .ico / 托盘图标
npm run desktop:smoke                           # 端到端自检：启动桌面程序、模拟手机扫码配对、杀掉 bridge 验证自动重启、截图
```

- 在 Node 20 上运行 electron-builder 若报 `ERR_REQUIRE_ESM`，先设置 `$env:NODE_OPTIONS="--experimental-require-module"`（Node ≥ 22 不需要）。
- 下载 Electron / NSIS 受网络限制时：`$env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"`、`$env:ELECTRON_BUILDER_BINARIES_MIRROR="https://npmmirror.com/mirrors/electron-builder-binaries/"`。
- 跨网络功能依赖原生模块 `node-datachannel`。打包时它连同 `detect-libc` 和 `@node-datachannel/win32-x64-msvc` 被放进 `resources\bridge\node_modules`（`extraResources`，位于 app.asar 之外，等效于 asarUnpack），所以安装后 bridge 子进程可以直接加载 `.node` 文件。

**手机 APK：** 需要 JDK 17 和 Android SDK（platform-tools、platforms;android-34、build-tools;34.0.0）。脚本默认使用 `%USERPROFILE%\jdk-17` 和 `%USERPROFILE%\android-sdk`，也可通过 `JAVA_HOME` / `ANDROID_HOME` 指定，**不会修改系统环境变量**。

```powershell
npm run android:debug     # 输出 dist-android\PocketPilot-debug.apk
# release：先准备 keystore，再设置环境变量（不要提交 keystore/密码）
$env:POCKETPILOT_KEYSTORE="C:\path\to\pocketpilot-release.keystore"
$env:POCKETPILOT_KEYSTORE_PASSWORD="******"
npm run android:release   # 输出 dist-android\PocketPilot-release.apk
```

Capacitor 工程在 `apps/android`（appId `com.pocketpilot.app`）。WebView 来源 `https://localhost` / `capacitor://localhost` 已默认加入 host 的 CORS 白名单（设置 `POCKETPILOT_CAPACITOR_ORIGINS=0` 可关闭）。

## 9. 高级用法：命令行启动 host（无桌面程序）

不想装桌面程序时，仍可以直接运行 bridge（先 `npm run build`）。**不要同时运行桌面程序和命令行 host 使用同一个端口。**

```powershell
npm run build; $env:POCKETPILOT_RTC="1"; $env:POCKETPILOT_REMOTE="1"; node scripts\serve-host.mjs --lan
```

- `POCKETPILOT_RTC=1`：启用 WebRTC + MQTT 远程通道，并在终端打印配对二维码和 6 位配对码；
- `POCKETPILOT_REMOTE=1`：远程模式，本机浏览器也必须配对；
- `--lan`：监听 0.0.0.0；只在本机试用可直接 `npm run host`（默认端口 47232）；
- 后台运行并写日志：`Start-Process node -ArgumentList 'scripts\serve-host.mjs','--lan' -RedirectStandardOutput host.log -RedirectStandardError host.err.log -WindowStyle Hidden`（先设好上面的环境变量）；
- 健康检查：`curl http://127.0.0.1:47232/api/health` 返回 `{"ok":true,...}` 即正常；
- 终端二维码过期后重启 host，或在已配对设备的设置页“扫码配对（跨网络）”里重新生成。

> 旧版本升级：环境变量 `MOBILEAGENT_*` 仍然兼容（等同于 `POCKETPILOT_*`）；首次启动时若只有旧目录 `~/.mobileagent`，会自动复制到 `~/.pocketpilot`（旧目录保留作备份），已配对设备不受影响。

## 平台接入与新功能（v0.3）

- **已支持的平台**：Cursor（命令行 `cursor-agent` / `agent`）、Claude Code、Codex、Gemini CLI、OpenCode、DeepSeek Harness、Trae CN、Grok。总览只统计电脑上真实检测到的平台。
- **Cursor**：官方安装 `irm 'https://cursor.com/install?win32=true' | iex`，装好后在电脑上运行 `cursor-agent login`（浏览器授权）或在设置里保存 `CURSOR_API_KEY`。
- **Trae CN**：编辑器的对话记录是加密数据库，读不到；只读取它打开过的项目。装了 TRAE CLI（`traex` / `traecli`）后才可对话和读会话（该路径未在本机验证）。
- **Grok**：在“设置 → 智能体平台 → Grok → 连接与登录”保存 `XAI_API_KEY`，走 xAI API 对话（只有文字对话，不能改文件），用量来自 API 返回；也可使用官方 Grok Build 命令行 `grok`（`irm https://x.ai/cli/install.ps1 | iex`）。
- **任务完成提醒**：设置 → 通知。APK 内用系统通知（后台）/应用内弹窗（前台），网页用浏览器通知。
- **设置与选择**：设置是多级列表（平台 → 二级菜单 → 详情）；“会话”标签按 平台 → 项目 → 会话 逐级选择。系统返回键/手势逐级返回。
