使用手册

电脑跑代理，手机只负责连接和下指令。更完整的安装说明在仓库 docs/使用指南.md。

01

电脑端

安装 PocketPilot-Setup.exe，或在仓库根目录执行 npm run desktop。窗口显示服务状态、局域网地址、远程通道、蓝牙状态、二维码和 6 位配对码。关闭窗口会进托盘。

02

手机端

npm run android:debug 得到 APK。打开后扫描电脑上的二维码。同一 Wi-Fi 也可以填写 http://电脑IP:47241 和配对码。

03

通信方式

已配对后自动选择：局域网 HTTP，然后加密远程通道，最后是近距离蓝牙。设置 → 通信方式可以查看当前通道，或改成手动。桌面端「允许蓝牙」会重启服务。

04

蓝牙

需要 Windows 10 1803 或更新，并打开系统蓝牙。Windows 11 还要允许桌面应用使用蓝牙。先扫一次二维码，蓝牙才使用同一把密钥。不需要更换系统蓝牙驱动。

05

代理

默认是演示模式。关掉之后，宿主会在你选的目录里启动 agent、claude、codex、opencode、gemini 或 dsh。密钥写在这台电脑的 ~/.pocketpilot，不会进仓库。

06

开发

npm test 和 npm run typecheck 做检查。npm run dev 的界面在 47231，宿主在 47232。要让其他设备必须配对，用 npm run host。
